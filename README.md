# Vishal Mehra — Portfolio (GitHub Pages)

A clean, modern one‑page portfolio for performance marketing. Deployed via GitHub Pages.

## Quick start
1. Upload `index.html` and `style.css` (and the `assets` folder) to your `USERNAME.github.io` repo.
2. In **Settings → Pages**, set Source to `main` and Folder to `/ (root)`.
3. Open `https://USERNAME.github.io`.

## Customise
- Edit text in `index.html` (About, Skills, Projects, Contact).
- Replace `assets/placeholder.png` with real screenshots.
- Update links (LinkedIn, Google Sheets) as needed.
